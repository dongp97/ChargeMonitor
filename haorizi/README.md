# 好日子

把重要的日子记一次，往后每年它自己会来找你。

一个纯本地的 Android 小应用：家人的生日、结婚纪念日、还有那些一年只提醒一次的事。
不联网、不上传、不需要注册，数据只存在你的手机里。

---

## 为什么值得装

**农历生日是刚需，但大部分 App 做不利索。**
家里长辈的生日多半按农历记（八月十五、腊月初八）。这个 App 内置了完整的
1900–2100 年农历换算，填农历日期，它自己算出今年是几月几号、星期几。

**「农历三十」遇上小月会自动落到廿九。**
腊月只有廿九天的年份，除夕照样能提醒 —— 这不是特例处理，是写进推算逻辑里的。
（民间「廿九当三十过」）

**提前提醒可以按天设。**
提前 30/15/7/3/2/1 天和当天，任意勾选。系统通知推送，不用打开 App。

**一眼看清「最近要过哪个日子」。**
首页主卡片永远是真正最近的那一个，下面是未来 90 天和更远的。
日历页给每天标了农历和节气。

## 功能一览

| 页面 | 内容 |
|---|---|
| 近期 | 今日公历/农历/干支/节气/星座 · 最近的日子大卡片 · 90 天内 · 更远 · 已过去 |
| 全部 | 搜索（名字/备注/关系）· 按类型筛选 · 按临近/名字/添加排序 |
| 日历 | 月历 + 每日农历/节气 · 有安排的日子打彩色圆点 · 点日期看当天安排 |
| 设置 | 主题（跟随系统/浅色/深色）· 提醒开关与时间 · 通知权限状态 · 备份导入导出 · 分享清单 |

其他：置顶、备注、关系标签、一键添加 16 个常用节日、备份成 JSON 存到「下载」目录、生成文字清单分享给家人。

## 技术说明

- **Android 原生壳 + 本地 Web 界面**：`minSdk 26` / `targetSdk 35`，Kotlin + WebView（`WebViewAssetLoader` 以 https 源提供本地资源，localStorage 可靠持久化）。
- **农历引擎**（`assets/lunar.js`）：1900–2100 年，内置农历数据表 + 节气近似公式，公历↔农历双向往返、干支、生肖、星座、闰月、小月顺延。
- **逻辑层**（`assets/core.js`）：数据规范化、日期推算、提醒生成、备份序列化。不碰 DOM，可在 Node 里直接测。
- **提醒**：JS 算出未来 120 天内所有触发时刻（epoch 毫秒）推给原生，Kotlin 用 `AlarmManager` 槽位式排闹钟；开机/改时间由 `BootReceiver` 从 `SharedPreferences` 恢复，不依赖 WebView。
- **精确闹钟**被系统拒绝时自动降级为普通闹钟，提醒不会静默丢失。

## 测试

三层测试，都在本地跑，不需要设备：

```bash
node tools/test-lunar.js   # 农历引擎：183 项
node tools/test-core.js    # 逻辑层：80 项
node tools/test-ui.js      # 界面层（jsdom 真实点击）：121 项
```

覆盖的关键点：

- 60 个已知年份的春节公历日期（1900–2100，含外部万年历核对）
- 73,000 个采样日的公历↔农历往返一致性
- 201 年农历月连续性（每月初一必须紧接上月最后一天）
- 闰月表、除夕在小月年份落到廿九、八月三十同理
- 节气、干支、生肖、星座
- 提醒的时间点、升序、去重、窗口过滤、开关联动
- 备份往返、合并去重、坏文件拒绝
- 界面：搜索/筛选/排序、日历格子农历与算法逐格比对、新建/编辑/置顶/删除、导入覆盖与合并、清空、返回键、HTML 注入转义

`test-ui.js` 需要 `jsdom`。

## 构建

本机不需要 Android SDK。推到 GitHub 后由 Actions 编译：

```bash
gh workflow run workflow-haorizi-build.yml
# 构建产物：haorizi/app/build/outputs/apk/debug/app-debug.apk
# workflow 会先 find 定位、再 cp 到 dist/ 后上传，artifact 名 haorizi-apk
```

> 注意 `paths` 过滤必须包含 workflow 文件自身的路径，否则「只改 workflow」
> 的推送不会触发构建（`BUILD_STAMP` 用于保证每次推送都有 `haorizi/**` 变更）。

## 数据

所有数据存 `localStorage`（键 `haorizi.v1`）。卸载即消失，删之前记得「导出备份」。

备份格式：

```json
{
  "app": "好日子",
  "v": 1,
  "exportedAt": "2026-09-10T08:00:00.000Z",
  "settings": { "theme": "system", "remindTime": "09:00", "defaultRemind": [7, 1, 0], "notifyOn": true },
  "items": [
    { "id": "i...", "kind": "birthday", "name": "妈妈", "dateType": "lunar",
      "month": 8, "day": 15, "year": 1962, "repeat": "year",
      "remind": [7, 3, 1, 0], "relation": "家人", "note": "", "pinned": false }
  ]
}
```

`dateType` 为 `lunar` 时，`month`/`day` 是农历月日，`isLeap` 表示闰月；
`year` 留空表示不计算年龄、每年重复。
